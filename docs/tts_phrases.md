# TTS 文案对照（建议在 Cursor/VSCode 查看）

这个文件用于保存**可读中文**与对应的 **GBK 字节串**。
在 `C` 代码里建议只使用 `\x..` 字节串，避免 Keil 中文乱码导致文本被破坏。

## 当前使用（长按测试语音）

- 中文：这是科大先进技术研究院
- GBK：`\xD5\xE2\xCA\xC7\xBF\xC6\xB4\xF3\xCF\xC8\xBD\xF8\xBC\xBC\xCA\xF5\xD1\xD0\xBE\xBF\xD4\xBA`
